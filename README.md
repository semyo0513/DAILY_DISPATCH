# AI 융합교육 매거진

Gmail로 도착하는 브리핑 메일(예: `[AI 융합교육 데일리 브리핑] 2026-08-03 최신 실천사례 및 에듀테크 동향`)을
매거진 형태의 카드 목록으로 보여주는 순수 프론트엔드 웹앱입니다. 서버·백엔드 없이 GitHub Pages에서
바로 동작하며, 본인의 Google 계정으로 로그인해 본인 Gmail만 읽습니다(읽기 전용 권한).

## 1. 기능 요약

|기능        |설명                                                               |
|----------|-----------------------------------------------------------------|
|Google 로그인|Google Identity Services로 클라이언트 단에서 직접 로그인 (Gmail 읽기 전용 권한만 요청)  |
|메일 검색     |제목 키워드 + (선택)발신자 조합으로 Gmail 검색 API 호출                            |
|매거진 카드    |제목의 `[분류] 날짜 헤드라인` 형식을 자동 분해해 분류 칩·발신 번호·요약으로 카드 구성              |
|상세 보기     |카드 클릭 시 본문을 지연 로딩(클릭한 것만 전체 본문 요청) 후 안전하게 표시                     |
|검색·분류 필터  |이미 불러온 기사 안에서 제목/요약 검색, 분류별 필터링                                  |
|캐시        |localStorage에 목록·본문을 저장해 재방문 시 즉시 표시, 캐시 초기화 버튼 제공               |
|보안        |DOMPurify로 메일 HTML을 정제하고, 스크립트 실행이 불가능한 `sandbox` iframe 안에서만 렌더링|

## 2. 파일 구성

```
index.html   메인 페이지 (마크업 + 모달 2종: 상세보기/설정)
style.css    디자인 토큰 및 전체 스타일
app.js       Gmail API 연동, OAuth 로그인, 파싱·렌더링 로직
README.md    이 문서
```

## 3. 사전 준비: Google Cloud OAuth 클라이언트 ID 발급

메일을 읽으려면 **본인 소유의 무료 Google Cloud 프로젝트**가 필요합니다. (1회만 설정하면 됩니다.)

1. <https://console.cloud.google.com> 접속 → 새 프로젝트 생성 (예: `ai-edu-magazine`)
1. 좌측 메뉴 **API 및 서비스 → 라이브러리** → `Gmail API` 검색 후 **사용 설정**
1. **API 및 서비스 → OAuth 동의 화면**
- User Type: **외부** 선택 → 앱 이름/이메일 등 최소 정보만 입력
- **테스트 사용자**에 본인 Gmail 주소를 추가 (검증 전이라 “Google에서 확인하지 않은 앱” 화면이 뜨는데,
  로그인 시 **고급 → (앱 이름)로 이동(안전하지 않음)** 을 누르면 정상적으로 로그인됩니다. 본인만 쓰는 개인
  프로젝트이므로 정상적인 절차입니다)
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
- 애플리케이션 유형: **웹 애플리케이션**
- **승인된 자바스크립트 원본**에 배포할 GitHub Pages 주소를 추가
  - 예: `https://<깃허브아이디>.github.io`
- 생성된 **클라이언트 ID** (`xxxxxxxx.apps.googleusercontent.com` 형식)를 복사해 둡니다

> 클라이언트 ID는 비밀값이 아니라 공개되어도 되는 값입니다(브라우저에 그대로 노출됩니다).
> 대신 위 3단계에서 “승인된 원본”을 본인의 GitHub Pages 주소로 제한해 두었기 때문에 다른 도메인에서는
> 이 클라이언트 ID로 로그인 창을 띄울 수 없습니다.

## 4. GitHub Pages 배포

1. GitHub에 새 저장소 생성 (예: `ai-edu-magazine`)
1. `index.html`, `style.css`, `app.js` 세 파일을 저장소 루트에 업로드 후 커밋
1. 저장소 **Settings → Pages** → Source를 `main` 브랜치 `/ (root)` 로 설정 → 저장
1. 1~2분 후 `https://<깃허브아이디>.github.io/ai-edu-magazine/` 로 접속

## 5. 첫 실행

1. 접속하면 설정 창이 자동으로 열립니다 → **3번에서 발급받은 Client ID** 붙여넣기
1. 검색 키워드는 기본값 `AI 융합교육`이 들어있습니다. 메일 제목이 예:
   `[AI 융합교육 데일리 브리핑] 2026-08-03 최신 실천사례 및 에듀테크 동향`
   이므로 **“AI 융합교육”이라는 단어가 유지되는 한** 날짜나 뒷부분 문구가 바뀌어도 계속 검색됩니다.
   나중에 메일 제목 형식 자체가 크게 바뀌면 이 설정에서 키워드만 수정하면 됩니다.
1. (선택) 발신자 이메일 주소를 알고 있다면 **발신자** 칸에 입력해두면 제목이 완전히 바뀌어도
   가장 안정적으로 걸러집니다. Gmail 검색창에서 해당 메일을 열어 보낸 사람 주소를 확인할 수 있습니다.
1. 저장 → **Google로 로그인** → 본인 Gmail 계정 선택 → 권한 동의
1. 자동으로 메일함을 검색해 매거진 카드가 표시됩니다

## 6. 참고 사항

- 로그인 유지 시간은 Google 액세스 토큰 기준 약 1시간이며, 만료되면 다시 로그인 버튼을 눌러주시면 됩니다.
- “한 번에 불러올 개수”를 늘리면 최초 목록 조회 API 호출은 그대로지만, 이후 본문은 클릭한 기사만
  불러오므로 Gmail API 사용량에 큰 영향은 없습니다.
- 본문은 스크립트를 실행할 수 없는 `sandbox` iframe 안에서만 표시되어, 메일에 악성 스크립트가
  포함되어 있어도 페이지에 영향을 줄 수 없습니다.
